**BUG#60 FIXED 2026-07-05 (8cd60ed, backend-only, fixpoint n2==n3)** — nested `Option[Option[i32]]` match trả 8 thay vì 42. Root cause qua **objdump** (không đoán): `regalloc_is_16byte` case **OP_DEREF** (x86_selector.ax ~611) trả `true` cho MỌI deref result size-16, THIẾU guard `not type_is_aggregate` mà case COPY/CALL/else đã có (từ BUG#56). Nested `Some(inner)` bind `inner` qua OP_DEREF typed Option (entry.size 16) — nhưng vreg giữ BOX POINTER 8B, không phải 16B inline. Bị báo 16-byte-inline → `inner` có home 16B inline → mọi use (disc-test inner match + payload OP_DEREF) spill-reload bằng **LEA(&slot) thay MOV(slot→reg)** → đọc ĐỊA CHỈ slot làm box → double-deref rác (exit 8). Fix: thêm `and not type_is_aggregate(table, type_id)` vào case OP_DEREF (chỉ str thật type-12/ptr[str] mới inline-16). **Kỹ thuật tìm ra**: objdump -d -M intel binary, thấy `lea r11,[rbp-0x18]` + `mov edx,[rax]` (rax=&slot) thay vì load box. Fixpoint: n1≠n2 EXPECTED (fix đổi codegen của chính compiler — Option/Result deref), gate = **n2==n3** (chạy tay hop n3).
